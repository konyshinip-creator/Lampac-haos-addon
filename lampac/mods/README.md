# Дополнительные модули Lampac

Модули из этой папки работают в **любом** Lampac NextGen, не только в аддоне
Home Assistant. Каждый модуль — обычная папка с `manifest.json` и `.cs`-файлами,
Lampac компилирует их Roslyn-ом при старте (и пересобирает на лету при
изменении файлов, `"dynamic": true`).

| Модуль | Раздел | Что даёт |
|---|---|---|
| `Senku` | Онлайн (аниме) | senku.one: поиск, озвучки Kodik (до 720p) и собственные mp4 до 1080p/2160p. Ключ тайтла — Shikimori ID |
| `Anistar` | Онлайн (аниме) | anistar.org: свой плеер AniStar (озвучка, многоголосая, субтитры). Поток идёт через прокси Lampac, потому что CDN требует Referer |
| `Animaunt` | Онлайн (аниме) | animaunt.org: плеер OpenNI, прямые mp4 до 1080p. Тайтлы с плеером Kodik пропускаются — их отдаёт балансер Kodik |
| `AnimeFox` | Онлайн (аниме) | animefox.org: поиск, озвучки и серии плеера Kodik. Поток отдаёт встроенный модуль Kodik, он должен быть включён. Раздел сайта /hentai/ не показывается |
| `AniTokyo` | Онлайн (аниме) | anitokyo.tv: поиск, озвучки и серии плеера Kodik. Поток отдаёт встроенный модуль Kodik, он должен быть включён. Серии Sibnet и VK не показываются |
| `Hentasis` | 18+ (SISI) | hentasis1.top: каталог, поиск, серии с озвучкой и субтитрами. **Выключен по умолчанию** |
| `HentaiUkr` | 18+ (SISI) | hentaiukr.com: каталог, поиск, прямые mp4 до 1080p. Тайтлы с тегами «Школа» и «Школярки» и тайтлы без тегов не показываются, это не настройка. **Выключен по умолчанию** |
| `AnimeMonitor` | Служебный | Мониторинг доступности источников: страница `/animemon`, JSON `/animemon/status`, webhook при смене статуса |
| `LampacHub` | Служебный | Профили со своими закладками, историей, тайм-кодами и настройками, категории «Мои списки», вход устройств по 6-значному коду, админка `/hub`, плагин `/hub.js`. Подробнее — [ниже](#lampachub) |

## Установка в обычный Lampac

### Вариант 1: автоматически из GitHub (рекомендуется)

Создайте файл `mods/repository.yaml` в папке Lampac (или допишите в него,
если он уже есть):

```yaml
- repository: https://github.com/konyshinip-creator/Lampac-haos-addon
  branch: main
  modules:
    - lampac/mods/Senku
    - lampac/mods/Anistar
    - lampac/mods/Animaunt
    - lampac/mods/AnimeFox
    - lampac/mods/AniTokyo
    - lampac/mods/Hentasis
    - lampac/mods/HentaiUkr
    - lampac/mods/AnimeMonitor
    - lampac/mods/LampacHub
```

При каждом старте Lampac проверяет последний коммит ветки и, если он
изменился, скачивает модули в `module/<имя репозитория>/<Модуль>/`.
Лишние строки из списка можно убрать. Вместо `konyshinip-creator/Lampac-haos-addon`
можно указать зеркало `https://github.com/infomirlabtest-alt/Lampac-haos-addon-`,
содержимое одинаковое.

### Вариант 2: вручную

Скопируйте нужные папки в `mods/` Lampac (`mods/Senku`, `mods/Anistar`, …)
и перезапустите сервер. В Docker — примонтируйте их томом:

```yaml
services:
  lampac:
    image: ghcr.io/lampac-nextgen/lampac
    volumes:
      - ./mods/Senku:/lampac/mods/Senku
      - ./mods/Anistar:/lampac/mods/Anistar
```

### Подключение в Lampa

Модули работают на сервере, отдельных плагинов у них нет. В Lampa
(**Настройки → Расширения → Добавить плагин**) достаточно стандартных плагинов
Lampac:

- `http://<IP Lampac>:9118/online.js` — Senku, AniStar, AniMaunt, AnimeFox и AniTokyo появятся в
  списке источников кнопки **Онлайн** в карточках аниме;
- `http://<IP Lampac>:9118/sisi.js` — Hentasis и HentaiUkr появятся в разделе 18+.

Если источника нет в списке, проверьте, что он включён в `init.conf`
(`"enable": true`, см. ниже), и посмотрите `/animemon` — сайт может быть
недоступен.

## Настройка (`init.conf`)

Все модули читают свою секцию из `init.conf` и подхватывают изменения без
перезапуска. Онлайн-модули поддерживают стандартные поля Lampac
(`enable`, `host`, `displayindex`, `useproxy`, `streamproxy`, …).

```json
{
  "Senku":    { "enable": true },
  "Anistar":  { "enable": true, "host": "https://anistar.org" },
  "Animaunt": { "enable": true },
  "AnimeFox": { "enable": true },
  "AniTokyo": { "enable": true },
  "Hentasis": { "enable": true },
  "HentaiUkr": { "enable": true },
  "Xhamster": { "host": "https://ua.xhamster2.com" },
  "AnimeMonitor": {
    "enable": true,
    "interval": 10,
    "timeout": 15,
    "webhook": "http://homeassistant.local:8123/api/webhook/anime-sources"
  }
}
```

Если сайт переехал на новое зеркало, достаточно поменять `host` в его секции.
Так же настроен встроенный Xhamster: новый модуль ему не нужен, адрес зеркала
задаётся полем `host`, в аддоне Home Assistant — опцией `xhamster_host`.

### Монитор доступности

По умолчанию проверяются senku.one (JSON-поиск), anistar.org, animaunt.org,
animefox.org, anitokyo.tv, hentasis1.top, hentaiukr.com (по `robots.txt`), плеер
OpenNI и Kodik. Состояния:

- `up` — сайт отвечает как ожидается;
- `challenge` — ответила защита (Cloudflare/DDoS-Guard), 403/429 или пришла
  HTML-заглушка вместо ожидаемого ответа;
- `down` — ошибка сети, таймаут или другой HTTP-код.

Свой список целей задаётся полем `targets`; он целиком заменяет список по
умолчанию:

```json
{
  "AnimeMonitor": {
    "targets": [
      { "name": "Anistar", "url": "https://anistar.org/robots.txt", "marker": "User-agent" },
      { "name": "Senku", "url": "https://senku.one/senku-api/api/v2/search?q=naruto", "marker": "\"ok\":true" }
    ]
  }
}
```

`/animemon?refresh=true` и `/animemon/status?refresh=true` запускают
проверку сразу.

Webhook получает `POST` с JSON при каждой смене состояния:

```json
{ "source": "Anistar", "url": "https://anistar.org/robots.txt", "previous": "up", "state": "down", "code": 0, "error": "timeout", "checked": "2026-11-04T18:00:00Z" }
```

### Home Assistant

REST-сенсор (`configuration.yaml`):

```yaml
rest:
  - resource: http://<IP Lampac>:9118/animemon/status
    scan_interval: 300
    sensor:
      - name: "Аниме-источники доступны"
        value_template: "{{ value_json.up }}/{{ value_json.total }}"
        json_attributes:
          - down
          - sources
```

Уведомление при падении источника через webhook (укажите
`http://<IP HA>:8123/api/webhook/anime-sources` в опции `monitor_webhook`
аддона или в `AnimeMonitor.webhook`):

```yaml
automation:
  - alias: "Аниме-источник изменил статус"
    trigger:
      - platform: webhook
        webhook_id: anime-sources
        local_only: true
    action:
      - service: notify.notify
        data:
          message: "{{ trigger.json.source }}: {{ trigger.json.previous }} → {{ trigger.json.state }} {{ trigger.json.error or '' }}"
```

## LampacHub

Профили и вход устройств без пароля на ТВ. Работает в любом Lampac NextGen;
в аддоне Home Assistant включается опцией `enable_hub`.

**Как устроено.** Пока в accsdb нет пользователей, Lampac раздаёт всем своим
клиентам одну общую идентичность (`database/instance.uid`), и Sync/TimeCode
делят данные по `profile_id`. LampacHub ведёт список профилей и устройств и
выставляет на устройстве `lampac_profile_id`, так что у каждого профиля свои
закладки, история и тайм-коды. Профиль «Основной» (`profile_id` = `0`) — это
общая область, в которой лежит всё накопленное до LampacHub. Включать accsdb
не нужно: токен устройства служит только для входа в LampacHub.

1. Включите модуль (секция ниже) и `Sync` с `TimeCode` (`BaseModule.SkipModules`
   не должен их содержать).
2. Подключите плагин `http://<IP Lampac>:9118/hub.js`. Если Lampa открывается
   с самого Lampac, проще добавить его в `init.conf`, тогда он загрузится на
   всех устройствах сам:

   ```json
   {
     "LampaWeb": {
       "customPlugins": [
         { "url": "{localhost}/hub.js", "status": 1, "name": "LampacHub", "author": "lampac-haos-addon" }
       ]
     }
   }
   ```

3. Откройте `http://<IP Lampac>:9118/hub` (пароль — root-пароль Lampac из
   файла `passwd`) и создайте профили.
4. На устройстве: **Настройки → LampacHub → Войти по коду** (или пункт меню
   «Войти в LampacHub»). Устройство покажет 6 цифр, введите их в админке и
   выберите профиль. Код живёт 10 минут.
5. Профиль меняется пунктом меню «Профиль: …». При смене локальные закладки и
   тайм-коды устройства очищаются и загружаются с сервера для нового профиля.

`hub.js` сам подгружает `bookmark.js` и `timecode.js`, если их ещё нет.
Данные модуля — `database/LampacHub.sql`, загруженные аватары —
`database/LampacHub/avatars/`.

**Настройки профиля.** Настройки Lampa общие для всех устройств профиля:
язык, тема, вид интерфейса, источник каталога, парсер, TorrServer и
параметры плагинов. Плеер, размер интерфейса, навигация, кеш и другие
параметры конкретного экрана остаются на устройстве. Хранятся в
`database/LampacHub.sql`. Изменения уходят на сервер через пару секунд, а
другое устройство профиля применяет их при следующем запуске Lampa (и один
раз перезапускается). Галочка «плагины» у профиля переносит ещё и плагины,
установленные в Lampa вручную. По умолчанию она выключена, потому что не
каждый плагин работает на любом устройстве. «Сбросить» в админке забывает
сохранённые настройки: следующее устройство профиля сохранит свои.

**Мои списки.** Категории как в Yummy/Anihub:

| Категория | Где хранится |
|---|---|
| Смотрю, Планирую, Просмотрено, Отложено, Брошено | статусы Lampa `look`, `scheduled`, `viewed`, `continued`, `thrown` (Sync) |
| Избранное | `like` Lampa (Sync) |
| Пересматриваю | LampacHub (`database/LampacHub.sql`) |

Статус у тайтла один, новый снимает прежний. В карточке тайтла кнопка «Мой
список» ставит статус и Избранное, пункт меню «Мои списки» открывает любую
категорию.

В админке, в разделе «Списки», выбирается профиль. Вкладки сверху — категории
с числом тайтлов, слева — фильтры по типу (сериалы, фильмы, аниме), жанру и
году, над списком — поиск, сортировка и переключатель «плитки / таблица».
Фильтры сохраняются в адресе страницы, так что отфильтрованный список можно
открыть по ссылке. Там можно менять статус и
Избранное, убирать тайтлы из всех списков и истории (✕ на плитке или в строке
таблицы, или «Убрать из списков» для отмеченных), копировать и переносить
отмеченные тайтлы в другой профиль, искать возможные дубли (одно название и
год под разными id или несколько статусов сразу), а также экспортировать и
импортировать JSON (`format: lampachub-lists`; при импорте все записи файла
добавляются в выбранный профиль). Правки из админки записываются в базу Sync
так же, как это делает сам Sync, и устройства подхватывают их при следующем
запуске Lampa.

Под названием тайтла показываются сведения из TMDB: статус выхода (Выходит,
Планируется, Завершён, Закрыт; у фильмов — Вышел), число сезонов и серий без
спецвыпусков и дата следующей серии, если она известна. Они подгружаются для
видимых карточек и кешируются в `database/LampacHub.sql`: выходящие сериалы
на 12 часов (и обновляются сразу после даты новой серии), завершённые — на 30 дней.

**Импорт** (раздел «Импорт» админки) добавляет тайтлы в списки выбранного
профиля:

- **Yummy Anime**: укажите ник, id или ссылку на профиль. Публичные списки
  читаются без входа. Закрытые нужно открыть в настройках приватности Yummy
  или вставить токен входа (он используется только на время импорта и нигде не
  сохраняется, пароль от Yummy не нужен). Статусы переносятся 1:1: Смотрю,
  В планах → Планирую, Просмотрено, Отложено, Брошено, а «Любимые» —
  в Избранное. «Пересматриваю» в Yummy нет. Проще всего — **файл экспорта**:
  на old.yummyani.me экспортируйте списки в JSON или HTML и загрузите файл
  кнопкой «Загрузить файл экспорта». Ни токен, ни вход не нужны.
- **Shikimori** (shikimori.io): открытый список читается по нику или ссылке на
  профиль без входа (`/api/users/{id}/anime_rates` и `/favourites`).
  Статусы: Смотрю, Запланировано → Планирую, Просмотрено, Отложено, Брошено,
  Пересматриваю, а Избранное → Избранное. Для закрытого профиля загрузите файл
  экспорта Shikimori (JSON или XML). Зеркало задаётся в `shikimori_api`.
- **MyAnimeList**: открытый список читается по нику
  (`myanimelist.net/animelist/{ник}/load.json`, без ключа API). Для закрытого
  загрузите экспорт (`myanimelist.net/panel.php?go=export`, файл `.xml.gz`
  можно не распаковывать). Watching → Смотрю, Plan to Watch → Планирую,
  Completed → Просмотрено, On-Hold → Отложено, Dropped → Брошено, пересмотр →
  Пересматриваю.
- **AniLiberty** (бывшая AniLibria): списки есть только у своего аккаунта,
  поэтому нужен вход. Удобнее по коду: «Войти по коду» в админке показывает
  код, его подтверждают на сайте AniLiberty в своём аккаунте, и пароль на
  сервер не попадает. Можно и логином с паролем. Пароль и токен используются
  только во время импорта и не сохраняются. Коллекции переносятся так:
  Смотрю, Запланировано → Планирую, Просмотрено, Отложено, Брошено, а
  Избранное → Избранное. Сопоставление идёт по id MAL/Shikimori, затем по
  русскому и английскому названию.
- **Anihub** (anihub.in.ua) не поддерживается: у сайта нет открытого API и
  экспорта, а закрытый API защищён от сторонних клиентов.
- **Резервная копия Lampa / CUB**: JSON с ключом `favorite` (объект или
  строка, как в localStorage Lampa). Карточки там уже с id TMDB и вливаются
  сразу.

Формат загруженного файла определяется сам: JSON Shikimori/Yummy
(`target_id`, `status`), HTML Yummy (`data-list-id`, `data-shiki-id`), XML
MyAnimeList/Shikimori (`series_animedb_id`, `my_status`), в том числе `.gz`.

Тайтлы Yummy, AniLiberty, Shikimori и MAL сопоставляются с TMDB сначала по id MAL/Shikimori через таблицу
[Fribb/anime-lists](https://github.com/Fribb/anime-lists) (кешируется в
`database/LampacHub/anime-list.json` на 7 дней), затем поиском по названию и
году (±1). Сезоны одного сериала в TMDB становятся одной карточкой со статусом
«самого живого» сезона. Что не сопоставилось, попадает в очередь «Ручное
сопоставление»: там можно выбрать кандидата, найти тайтл в TMDB вручную или
пропустить. После импорта показывается отчёт: сколько найдено по id, по
названию, сколько ушло в очередь и сколько карточек записано. Запросы к TMDB
идут с ключом `tmdb_key` (по умолчанию ключ самого Lampac) напрямую, а если
TMDB недоступен — через TMDB-прокси Lampac.

**Выбор сервера при запуске.** Если серверов Lampac несколько (дом, дача,
резервный), Lampa при старте показывает меню выбора. Список правится на
устройстве (Настройки → LampacHub → Серверы → «Изменить список»: добавить,
переименовать, изменить адрес, поднять в начало, удалить) и в админке
(раздел «Устройства» → «Серверы для меню выбора»). Устройства получают список
из админки сами (`GET /hub/servers`), текущий сервер в нём есть всегда. Меню
показывается один раз за запуск, если серверов больше одного; отключается
переключателем «Выбор сервера при запуске». При переходе список передаётся
новому серверу в адресе, поэтому его не нужно вводить заново. Ограничение:
меню загружается с сервера, на который смотрит приложение, и если он
недоступен, адрес придётся сменить в настройках самого приложения.

**Аватары.** В админке нажмите на аватар профиля: можно выбрать один из
готовых (папка модуля `avatars/`, свои `.svg` можно доложить туда же),
загрузить картинку с ПК (браузер обрежет её до квадрата 256×256) или указать
эмодзи или URL.

**Детский профиль** (галочка «детский» и возрастной лимит 0+/6+/12+/16+):

- пункт «Клубничка» скрыт, а сервер отвечает 403 на запросы `/sisi*` с
  `profile_id` детского профиля;
- карточка с возрастным рейтингом TMDB выше лимита (сначала RU, потом US и
  др.) и карточки 18+ не открываются;
- из списков TMDB убираются тайтлы 18+, при лимите ниже 16+ — ещё ужасы и
  триллеры; в каталоге (discover) фильмы дополнительно фильтруются по
  рейтингу MPAA на стороне TMDB.

**PIN.** Если в админке задан PIN (4–8 цифр), Lampa спрашивает его при
переходе с детского профиля на взрослый и при выходе из LampacHub. Сервер
проверяет PIN и даёт не больше 5 попыток за 10 минут на устройство.

Это защита от случайного просмотра, а не полноценный родительский контроль:
тайтл без рейтинга в TMDB может появиться в ленте, а очистка данных Lampa на
устройстве сбрасывает вход.

```json
{
  "LampacHub": {
    "enable": true,
    "code_ttl": 10,
    "account_name": "Основной",
    "load_sync": true,
    "tmdb_key": "",
    "yummy_app": "",
    "aniliberty_api": "https://aniliberty.top/api/v1",
    "shikimori_api": "https://shikimori.io",
    "anime_map_url": "https://raw.githubusercontent.com/Fribb/anime-lists/master/anime-list-full.json"
```

## Ограничения

- Форматы сайтов разобраны на нескольких тайтлах; при изменении вёрстки
